02 · Encore 是什么

让观众从"只能看"变成"也能玩"。

不打扰主播打游戏的前提下, 把每个高光时刻自动变成 30 秒可玩小游戏 —— 观众多了参与感和自己的短视频, 主播多了被动产出和打赏入口, 平台多了新 UGC 内容池和 install 漏斗。

STEP 01
👁

看见

AI 一直盯着主播在打什么,识别出 1v3 翻盘、抢龙、ace 这种高光时刻 ——
就是把"主播按高光按钮"这件事自动化。

STEP 02
🧬

转写

把刚才那个场面提炼成几个参数:什么游戏、几个敌人、什么武器、地图什么样 ——
用一份 JSON 描述清楚。

STEP 03
🎮

还原

30 秒内,客户端把这份 JSON 渲染成一个像素小游戏,
从屏幕底部弹出来给当时在场的观众玩。

05 · 不抢谁的盘子

跟互动游戏 / 弹幕游戏不抢盘子。

平台已有的互动游戏(萌宠快跑)和弹幕游戏跟 Encore 看起来像, 但底层逻辑不同 —— 服务不同主播、不同观众。

A · 互动游戏
🎁

萌宠快跑等

主播: 化身游戏角色,被观众礼物驱动加速 / 撞障碍。 全程 MC, 喊话求礼物。

观众: 间接 — 送礼影响主播游戏。

品类: 只接已经 mod 对接的合作游戏(目前 1-2 款)。FPS / MOBA / 吃鸡 接不进来。

B · 弹幕游戏
💬

轻量弹幕版

主播: 反应 + 接事件,但游戏被弹幕推着走。

观众: 间接 — 发弹幕 / 送礼影响事件。

品类: 平台定制的轻量游戏。同样不覆盖核心游戏品类。

C · Encore
⚡

观众自己玩

主播: 继续打 ranked, 什么都不变。 零参与也工作。

观众: 直接 — 每个在场观众都能自己上手玩 30s。

品类: 覆盖任何游戏(FPS / MOBA / 吃鸡 / GTA / Roblox), 占 TikTok Gaming 60-70% 内容。

一句话: 互动游戏服务"娱乐主播 + 想影响主播的观众"; Encore 服务"段位主播 + 想自己动手玩的观众"。 不抢盘子, 是品类保护型产品。
