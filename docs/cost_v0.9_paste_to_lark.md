### 6.2 成本($10 万/月封顶口径,过滤层 + 阶段化 + 日预算闸门)

**核心结论**: 所有直播间先走平台已有 **高光识别 + 游戏识别** 当过滤层, 再用模板覆盖大多数高光;**模型只负责"真生成"的部分, 且按日预算自动降级**。

**关键转变**: 上一版讲的 4B 高光/月是**平台大盘**, 不是 Encore 的模型调用量。 真实算法是:**先过滤, 再模板命中, 最后只把少数高价值高光交给模型真生成**。

#### 过滤层 — 4B 大盘怎么压到 4050 万月候选

| 过滤层 | 口径 | 量级 | 为什么这么算 |
|---|---|---|---|
| 游戏主播大盘 | 90 万主播/天 | 90 万 | TikTok Gaming LIVE 的开播主播池 |
| 值得生成 Encore 的主播 | 先取 50% | 45 万主播/天 | 低观看、低互动、重复内容先不做真生成 |
| 每个主播每天触发次数 | 最多 3 次 | 135 万次/天 | 不按每小时几十个高光全放, 避免打扰观众, 也控制预算 |
| 月候选池 | 135 万 × 30 天 | **4050 万次/月** | Encore 决定"模板还是真生成"的池子, 不是全跑模型 |

#### 第一阶段 (M9) · 接近零增量

- 5-20 款模板覆盖 Roblox / Free Fire / Minecraft / GTA V / PUBG Mobile / MLBB 等主流, 归到 3-4 类玩法
- 平台已有 [高光时刻] + [游戏 title 分类] 信号 → Encore 匹配模板, **运行时不调模型**
- **每路 Encore 启动增量 LLM 成本 ≈ $0**

#### 第二阶段 · 基础版 ($70-72K/月)

- 4050 万月候选, **80% 走模板, 20% 真生成 = 810 万次真生成/月**
- 模型路由: **80%** GPT-5.4 mini / Claude Haiku 4.5 · **15%** Claude Sonnet 4.6 · **5%** GPT-5.5 / Claude Opus 4.8
- 模型调用 **$55-57K/月** + 模板刷新 + 监控余量 **$15K/月** = **$70-72K/月**

#### 第二阶段 · 放量版 (≤$100K/月封顶)

- 同样的路由, 真生成比例提到 ~30% (约 1200 万次/月)
- **预算闸门按日封顶**: 月 $100K ÷ 30 ≈ 日 $3,333

| 当日预算使用率 | 系统动作 | 用户看到什么 |
|---|---|---|
| < 70% | 头部 GPT-5.5 / Opus, 中腰部 Sonnet, 普通 mini / Haiku | 高价值房间更贴近刚才那波高光 |
| 70-90% | 贵模型只给头部 + 厂商合作, 其他降到 mini / Haiku | 大多数体验不变, 少数普通房间回模板 |
| > 90% | 停普通房间真生成, 只保留模板 + 头部承诺 | 不超支, 仍能玩 Encore, 贴合度降低 |

#### 单次真生成成本(默认 2k 缓存 + 1k 动态输入 + 600 输出 + 15% 重试余量)

| 模型 | 输入 / 缓存 / 输出 (per 1M token) | 单次成本 | 用在哪 |
|---|---|---|---|
| GPT-5.5 | $5.00 / $0.50 / $30.00 | $0.0276 | 头部直播间、高价值高光、厂商合作游戏 |
| Claude Opus 4.8 | $5.00 / $0.50 / $25.00 | $0.0242 | 跟 GPT-5.5 同层 |
| Claude Sonnet 4.6 | $3.00 / $0.30 / $15.00 | $0.0145 | 中腰部高价值房间 |
| GPT-5.4 mini | $0.75 / $0.075 / $4.50 | $0.0041 | 大多数真生成调用 |
| Claude Haiku 4.5 | $1.00 / $0.10 / $5.00 | $0.0048 | 低成本兜底 |
| GPT-5.4 nano | $0.20 / $0.02 / $1.25 | $0.0011 | 分类、打分、是否升级 |

#### 回本线

一次高光只生成 1 份玩法参数, 整个房间观众一起玩, 成本被全场摊薄。 按 $0.5 Enhance: GPT-5.5 ≈ 0.06 笔 / Sonnet ≈ 0.03 笔 / mini-Haiku ≈ 0.01 笔。 贵模型只用在头部房间 / 高传播高光 / 厂商合作。

#### 短视频渲染成本(全方案共用, 次要)

- 端侧 Canvas + MediaRecorder 合成 = **零服务端成本**
- 服务端重渲: 7.5M 条/天 × 0.5-1 CPU·秒 ≈ $50-200/天, 相对模型可忽略
